1. 한눈에 보기

2. 준비: Inno Setup 설치

Inno Setup은 Windows 설치 프로그램을 만드는 도구입니다. 빌드하는 PC에만 있으면 되고, 설치 exe를 받는 사용자에게는 필요 없습니다.

설치 명령

PowerShell에서 아래 명령을 한 번만 실행합니다. 관리자 권한이 필요 없습니다.

winget install --id JRSoftware.InnoSetup --exact --scope user

설치 위치는 %LOCALAPPDATA%\Programs\Inno Setup 6입니다. Program Files에 설치해도 빌드 스크립트가 찾습니다.

설치 확인

Test-Path "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe"

True가 나오면 준비가 끝난 것입니다. ISCC.exe는 Inno Setup의 명령줄 컴파일러이고, 한국어 화면에 쓰는 Languages\Korean.isl이 함께 설치됩니다.

그 밖에 필요한 것

항목쓰임
Rust (cargo)프로그램 빌드
저장소의 .venv라이선스 문서 생성
dist\simplerag모델 · 런타임 DLL · Visual C++ 런타임의 원본(dist-rust에 없을 때 가져옴)
디스크 여유 공간설치 exe 2개가 약 4GB이므로 D: 드라이브에 5GB 이상

3. 설치 파일 만들기

먼저 MoAISearch를 종료합니다. 실행 중이면 exe가 잠겨서 덮어쓰지 못합니다. 트레이 아이콘의 메뉴에서 종료하세요.

1단계: 배포 폴더 갱신

저장소 루트(D:\Project\SimpleRAG)에서 실행합니다.

powershell -ExecutionPolicy Bypass -File rust\build_dist.ps1

끝에 완료 — ...dist-rust가 나오면 성공입니다. ⚠️ 경고가 있으면 내용을 먼저 처리합니다.

2단계: 설치 exe 만들기

powershell -ExecutionPolicy Bypass -File rust\build_installer.ps1

이 PC에서는 2개 합쳐 약 90초 걸렸습니다. GGUF 모델은 압축해도 12%밖에 줄지 않아 그대로 저장하고, ONNX 모델과 tokenizer만 압축합니다.

결과

dist-rust\MoAISearch_Setup_0.1.0.exe                  (1.45GB)
dist-rust\MoAISearch_PrecisionModel_Setup_0.1.0.exe   (2.5GB)

5. 설치 파일에 들어가는 것과 빠지는 것

dist-rust에는 개발 PC의 데이터가 섞여 있습니다. 그래서 installer.iss는 폴더를 통째로 묶지 않고 넣을 파일을 하나씩 지정합니다.

구분파일이유
포함exe, DLL, runtime\실행에 필요
포함e5-small-ko, bge-reranker-base-int8, Qwen3-1.7B임베딩 · 리랭커 · 기본 모델
별도Qwen3-4B정밀 모드 전용(2.5GB). 추가 설치 파일에 들어감
포함config.yaml, 기본 사전, 라이선스 문서기본 설정과 고지 의무
포함빈 RAGSearchBox.ini저장소 원본에서 새로 만든 것. 검색 폴더가 비어 있음
제외rag_index\, bm25_index.*, meta.sqlite, index_state.json문서 내용이 들어 있음
제외dist-rust\RAGSearchBox.ini이 PC의 폴더 경로가 들어 있음
제외people.yaml, synonyms.yaml, synonym_*사용자 사전과 검색 기록
제외gen_backend.json, uploads\PC별 측정값, 올린 문서
installer.iss의 [Files]에 폴더 전체를 넣지 마세요. 인덱스가 설치 exe에 들어가면 문서 내용이 외부로 나갑니다.

6. 설치된 PC에서 일어나는 일

항목내용
설치 위치%LOCALAPPDATA%\Programs\MoAISearch. 앱이 exe 옆에 인덱스와 설정을 쓰기 때문에 Program Files를 쓰지 않습니다. 관리자 권한이 필요 없습니다.
선택 항목바탕 화면 바로 가기(기본 켬), 로그인 때 자동 시작(기본 끔)
첫 실행탐색기 창이 뜨고 "검색 폴더를 지정해 주세요" 안내 뒤 폴더 고르기 창이 열립니다.
정밀 모드기본 설치에는 모델이 없어, 켜도 기본 모델로 답하고 설정 창에 안내가 나옵니다. 앱을 끄고 추가 설치 파일을 실행하면 설치 폴더의 models에 들어갑니다. 기본 프로그램이 없으면 설치되지 않습니다.
업데이트새 설치 exe를 실행하면 프로그램만 바뀌고 RAGSearchBox.ini, config.yaml, 인덱스는 유지됩니다.
제거자동 시작 해제, 폴더 아이콘 복원 후 설치 폴더 전체(인덱스 · 정밀 모델 포함)를 지웁니다. 원본 문서는 건드리지 않습니다.
남는 것%LOCALAPPDATA%\RAGSearchBox-rs의 로그 · 대화 기록은 제거 후에도 남습니다.
WebView2런타임이 없으면 설치 시작 때 안내합니다. Windows 11에는 기본으로 있습니다.

7. 자주 하는 변경

버전 올리기

rust\ragsearchbox\Cargo.toml의 version을 고치고 1 · 2단계를 다시 실행합니다. 설치 exe 이름에 자동으로 반영됩니다.

배포하는 생성 모델 바꾸기

아래 파일을 함께 고칩니다. 하나라도 빠지면 경고가 나오거나 라이선스 문서와 실제 파일이 어긋납니다.

파일고칠 곳
rust\build_dist.ps1"생성 모델은 배포 대상만 건다" 아래 목록
rust\gen_licenses.pySHIP_SLLM, 새 모델이면 MODELS와 licenses\models\ 원문도
rust\installer.iss[Files]의 .gguf 줄 (기본 모델)
rust\installer_precision.issModelFile (정밀 모드 모델)

뺀 모델은 dist-rust\models에서도 지워야 합니다.

넣을 파일 추가하기

installer.iss의 [Files]에 한 줄 추가합니다. 사용자가 고칠 수 있는 파일이면 Flags: onlyifdoesntexist를 붙여 업데이트 때 덮어쓰지 않게 합니다.

8. 배포 전 확인 목록

  • build_dist.ps1 끝에 ⚠️ 경고가 없다.
  • LICENSES_MODELS.txt의 모델이 설치되는 모델과 같다.
  • 새 Windows 계정이나 다른 PC에 설치해 첫 실행, 인덱싱, 검색, AI 답을 확인했다.
  • 제거 후 설치 폴더가 사라지는지 확인했다.
  • 법무 검토를 받았다(라이선스 문서는 기술 조사 결과입니다).
EXAONE은 넣지 마세요. 비상업 라이선스라 상업 배포가 금지됩니다.
코드 서명이 없습니다. 서명하지 않은 exe는 다른 PC에서 SmartScreen 경고가 뜰 수 있습니다. 외부에 배포한다면 코드 서명 인증서가 필요합니다.

Inno Setup은 상업적 사용이 허용된 라이선스이고, 개발사는 상업 사용자에게 유료 라이선스 구매를 요청하고 있습니다.

9. 문제가 생기면

증상원인과 해결
"Inno Setup 6 이 없습니다"2장의 설치 명령을 실행합니다.
"건너뜀(실행 중이라 잠김)"앱이 켜져 있습니다. 트레이에서 종료하고 1단계를 다시 실행합니다.
"배포 대상이 아닌 모델이 배포본에 있음"dist-rust\models에 남은 파일을 지웁니다.
"빈 ini 에 폴더 값이 있습니다"RAGSearchBox\RAGSearchBox.ini의 Folders를 비웁니다.
Source file ... does not existdist-rust에 파일이 없습니다. 1단계를 먼저 실행합니다.
설치 때 "실행 중입니다"대상 PC에서 앱을 종료하고 다시 시도합니다.
설치 후 앱 화면이 뜨지 않음WebView2 Runtime을 설치합니다. 로그는 %LOCALAPPDATA%\RAGSearchBox-rs\log에 있습니다.
